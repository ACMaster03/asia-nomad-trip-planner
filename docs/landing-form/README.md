# The list form on journey.livhold.com

What is here and how it gets onto the page. Since 3 Oct 2026 the page itself is in
this repository, in `landing/` (see its README), and the form is written into it by
`node tools/landing-form.mjs`: nothing is pasted by hand any more. Before that the page was
hosted by ChatGPT, reached through a DNS record on Vercel (Patrik, 1 Oct). Everything the
form needs on our side lives here, in the app that serves livhold.com, and keeps working if
the landing page later moves to livhold.com itself or the app moves to a subdomain.

## How it works

1. The form posts the answers as JSON to `https://livhold.com/api/journey-signup`
   (`product/src/app/api/journey-signup/route.ts`). Nothing but that address is in
   the page: no Supabase key, no table name.
2. The endpoint checks the answers (`product/src/lib/journey/signup.ts`, the same
   rules as the form) and stores one row in `journey_signups` (migration 44) with
   the public key, which may add rows and never read them.
3. A daily job deletes rows older than 12 months, the period the privacy policy promises.
4. The list is read in the Supabase dashboard: Table editor → `journey_signups`.

## What to paste into journey.livhold.com

Kept for reference: since 3 Oct all three pieces below are already in
`landing/public/index.html`. A paste is only needed if the page goes back to a host.

Three pieces. The paste holds a `<style>` and a `<script>` block; the host has to
allow both, which nobody has checked yet. If it strips scripts, the form cannot
run there and needs another way in (a page on livhold.com in an iframe).

**The form.** The whole of `livhold-journey-form.paste.html`, in the closing
section, directly under the "Start using Livhold" button. It is self-contained:
its own styles (`.lh-*`), its own script. The page already loads Lora and Work Sans.

**The hero link.** Under "Start your journey":

```html
<a href="#tell-us">Leaving later? Tell us when →</a>
```

It scrolls to the form. For a smooth scroll that respects "reduce motion", the
page's CSS needs:

```css
@media (prefers-reduced-motion: no-preference) { html { scroll-behavior: smooth; } }
```

**The footer.** Two links, which the page has none of today:

```html
<a href="https://livhold.com/privacy">Privacy</a> · <a href="https://livhold.com/terms">Terms</a>
```

## Test, after pasting

- Submit once for real: the row appears in Supabase → Table editor → `journey_signups`.
- Press "Count me in" with nothing filled in: a message under each of the three
  required answers, and "Almost there." above the button.
- Cut the connection (devtools → Network → Offline) and press again: "You seem to
  be offline" (or "That didn't go through"), and the answers stay.
- At phone width (390 px): First name and Email stack; nothing is cut off.
- Tick the call box and submit: the thank-you ends "Talk soon."

## If the small print under the button changes

Bump `consent_text_version` in the preview's script (today `"2026-10-01"`) and
re-run the generator, so each row records which wording the person agreed to.
