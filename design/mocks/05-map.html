Arcs are derived, not drawn by hand: gold solid = booked transport (the Budapest→Bangkok flight, Aug 31); dashed = planned legs generated from the Itinerary stop order. Reordering stops in Itinerary re-draws arcs instantly (client-side, no save round-trip). Pin numbers = itinerary order; ⌂ home is unnumbered.
Hazard glyphs: 🌀 monsoon months per coast come from the curated country catalogue (admin-maintained, per city/coast + month range); ⚠ seismic zones are a static bundled layer (USGS polygons, shipped with the app, no runtime fetch). Both only render when the Hazards layer is on; tapping a glyph opens a small explainer ("Vietnam central coast: typhoon season Oct–Dec — your Hoi An stop falls inside it").
Day/night shading is computed from real UTC solar position, so it is always astronomically correct. What timezone the printed clock labels use is configurable in ⚙ (see Settings overlay state).

🌀⚠Hazards
Auto-detect triggers: WebGL context creation fails, device memory < 4 GB, Save-Data header, or OS battery saver → lite renders automatically, with the amber banner + "Try 3D anyway" escape hatch. Manual override lives in ⚙ → Renderer; the choice is remembered per device.
Feature parity: same pins, arcs, hazard glyphs, country tap (simplified shapes) and the same country panel / live ring — lite applies to every map state, not just planning. Dropped: day/night terminator shading, arc animation, position pulse (static ring instead). It's plain SVG: crisp at any zoom, ~0 GPU cost.
Lite doubles as the snapshot renderer for static exports (e.g. the follower notification e-mail embeds a route image) — one codepath, two uses.
