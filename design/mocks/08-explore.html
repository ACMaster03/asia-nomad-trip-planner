🛠 ADMIN Catalogue editing mode
Changes are DB-driven — they go live for every trip instantly. No deploy, no app update. Every edit is audit-logged (who, field, old → new).
Role gate: only the admin role sees pencils and add-rows; owner/co-editor get the read-only city view (their own notes stay editable there). Currently Patrik holds admin for his own catalogue; when the product goes multi-tenant, catalogue admin becomes a separate global role.
