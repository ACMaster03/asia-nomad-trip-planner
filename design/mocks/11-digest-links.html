Gmail / Apple Mail one-click unsubscribe

The headers below make the mail client show its own native Unsubscribe control next to the sender name — and trust it. No page is shown to the reader; the client POSTs in the background and reports success itself.

From: Asia 2026–27 <trip@nomad.example> To: mom@example.com Subject: 🧭 Asia 2026–27 — 3 updates List-Unsubscribe: <https://asia-nomad-trip-planner.vercel.app/api/digest/unsubscribe?t=c41a…> List-Unsubscribe-Post: List-Unsubscribe=One-Click
What has to be true
POST endpointSame token, no confirmation page, returns 200 with an empty body.
No auth, no cookiesThe POST comes from Google’s servers, not the reader’s browser.
IdempotentRepeat POSTs return 200 even when the row is already gone.
Takes effect at onceDeleted immediately, so the next cron run can’t send one more.
GET still humanThe same URL opened by a person renders the Unsubscribed page (state 4).
This is what turns “an ugly page that says unsubscribed” into a real unsubscribe that Gmail and Apple Mail recognise — and it protects sender reputation, because readers reach for the client’s own button instead of the spam button.
