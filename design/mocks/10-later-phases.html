📲 Nomad Go — native companion (Expo)

P4 design study

Four static endframe thumbnails — not a web screen. The native app is push-first: reliable notifications, offline check-ins and a home-screen widget are the reasons it exists. Planning stays on the web.

Architecture guardrails decided now: same Supabase backend + RLS (no new API surface), the PWA's offline check-in queue is written storage-agnostic so Expo reuses it, and the globe stays web-only — native ships a flat MapLibre map (smaller bundle, better battery). No admin/moderation surfaces on native. Monorepo: apps/web + apps/native, shared packages/core.
